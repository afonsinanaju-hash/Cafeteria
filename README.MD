# ☕ Café & Aroma

Bem-vindo ao **Café & Aroma**!

Este projeto consiste em um site desenvolvido para uma cafeteria, com o objetivo de apresentar o estabelecimento, seu cardápio e suas informações de contato de forma simples, agradável e organizada.

## 📌 Sobre o projeto

O site foi criado como um projeto de desenvolvimento web utilizando **HTML5** e **CSS3**.

### 🍰 O site apresenta

* ☕ Informações sobre a cafeteria
* 🍰 Cardápio de produtos
* 🏠 Sobre o estabelecimento
* 📍 Localização
* 📞 Informações de contato
* 🧭 Menu de navegação

## 💻 Tecnologias utilizadas

* HTML5
* CSS3

## 🎯 Objetivo

O objetivo deste projeto é praticar conceitos de desenvolvimento web e criar uma página simples e funcional para uma cafeteria.
